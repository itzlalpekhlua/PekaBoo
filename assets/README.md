# PekaBoo assets

Collected from the updated game source. All copied files are byte-for-byte identical to their originals. `manifest.json` records original paths, sizes, SHA-256 checksums, and the source commit.

- `branding/`: supplied source logo, transparent cutout, final menu logo, and its presentation shader.
- `icons/`: PNG game icon, Windows ICO, and Android adaptive foreground/background images.
- `splash/`: desktop and Android boot splash images.
- `chars/`, `furniture/`, `props/`, `vehicles/`: game models and their textures.
- `tex/`, `photos/`, `tv/`: world textures, photographs, and TV assets.
- `fonts/`: game fonts.
- `music/`, `songs/`, `sfx/`, `sfx2/`, `voice/`: game audio.

Godot-generated import metadata is omitted from this collection. Godot recreates it when importing assets. This folder is a collection for browsing and reuse; the running game still loads its original resource paths.
